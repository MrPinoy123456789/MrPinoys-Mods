# Handoff 2026-10-02 #1: fix prompt for Claude Code

Read `docs/playtests/2026-10-02-1.md` and `docs/playtests/LIVE_CHECKS.md` first.
The mod is `pocketdungeons/` (Java, Fabric, MC 26.2). House rule: never write
an em dash or a spaced double hyphen as punctuation in code, strings, or docs.

## Must-fix bugs

1. **PD-105 (Low): Lemon's journal can be taken from her menu.** Right-clicking
   Lemon opens a lodestone-style menu with the diary/journal item; the player
   can remove it. Lock the slot or make it a read-only GUI.

2. **PD-106 (Medium): mobs drop too much trimmed armour.** Trimmed armour
   should be rare; currently one room can produce multiple pieces. Audit the
   mob-drop / spawner loot tables and trim rates.

3. **PD-107 (Medium): non-chaotic spawners mix unrelated mob types.** A single
   room produced zombies, breezes, spiders and skeletons. Themed spawners
   should be narrow and consistent; keep a rare explicit "chaotic" variant if
   desired.

4. **PD-108 (Medium): some gear cannot be salvaged.** Diamond leggings were
   rejected by the Salvage Bench. Check `SalvageStation.classify` for tags,
   durability thresholds or origin rules that exclude valid drops.

5. **PD-109 (Medium): tripwire traps are clipped by the room shell.** The
   player suspects the bedrock shell pass deletes the traps. Move the trap
   assembly inward or narrow the room so the shell does not overwrite it.

6. **PD-110 (Low): spiders climb walls and get stuck in corners.** Likely a
   vanilla spider wall-climb issue in tight ceiling corners; consider geometry
   that prevents them from clinging in the corner seam.

7. **PD-111 (Low): spawner-gate message is vague.** "Not yet, 3/5 trial
   spawners cleared. Go finish the rest." should say "Clear 2 more spawners"
   or similar.

8. **PD-112 (Low): sculk omen line needs a sound.** The SENSOR line
   ("The sculk counts your steps...") should play a warden ambient sound.

## Owner decisions and design changes to implement

9. **Remove custom `max_stack_size` caps.** Use vanilla stack sizes. Leave the
   rationale in a comment or doc in case it is ever needed again.

10. **Mending as an expensive "lock in" operation.** Remove Mending from random
    loot enchants; make it a paid station action that locks a piece of gear.
    Decide whether a locked item is exempt from salvage and reroll.

    and their spawner pools: zombie, skeleton, creeper, wither skeleton,
    mounted, nether, cube, farm animal, ender, plus existing themes. Define
    rarities, tiers, and which rooms they apply to. This is design work; write
    a proposal doc (`docs/reference/THEME_TABLE.md`) before implementing.

12. **Add a "guard" starting kit** (sword + shield).

      affixes.

    - Add a progress bar with rewards at nodes.

15. **Loot changes:** ender chests in loot tables become obsidian.

17. **Omen feedback:** play a sound whenever the player gains omen.

18. **Dead-end fountain boon room.** Add a chance for a fountain in dead-end

21. **Echo shard economy tuning:** 1 guaranteed echo shard per completed

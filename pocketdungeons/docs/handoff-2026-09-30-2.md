## Start by asking the owner to choose the work order

Do not assume all findings should be fixed in one pass. Ask the owner which of
these tracks to do first, then make a short plan before editing:

1. **Runtime blockers:** PD-93 first. A rolled anomaly room cannot stamp because
   the planner uses the anomaly manifest while `LayoutStamper` resolves the
   normal manifest. This can hard-block a door.
2. **Harness reliability:** PD-79 needs fresh diagnosis. Some player questions
   reached Lemon, but several asks timed out and surfaced only with
   `lemon unanswered`. Determine whether this is a wait-wake bug, agent latency,
   or both. PD-80 had one clean quiet timeout, so keep it under observation but
   do not reopen it on this evidence alone.
3. **Inventory and loot correctness:** PD-95 makes ordinary tagged loot fail to
   stack with identical plain loot. This caused repeated false duplication and
   inventory-clutter reports.
4. **Economy usability:** PD-96 makes the implemented Salvage Bench invisible.
   The player's preferred shape is that every non-sneak grindstone use opens the
   modified GUI, with vanilla disenchanting available as a separate button for a
   single disenchantable item.
5. **Reward integration:** PD-94 makes Boss Stone loot appear when Kamu Totems
   is absent. Decide whether to gate the loot, mark it dormant, or remove it.
6. **Post-fix live checks still owed:** PD-78 needs a live `blaze_cellar` roll;
   PD-92 needs a live max-omen death and re-entry; PD-80 needs more quiet waits.

## Design findings to discuss, not automatically implement

These are player requests or ideas. Ask the owner what belongs in the next build
before changing behavior:

- Omen granularity: death should add omen; proposed baseline 10 plus 5 per extra
  party member; Totems of Undying could be consumed to reduce omen by 1.
- Merchants: room encounters that buy clutter and sell useful items; rare
  merchants could sit behind Ordeal access.
- Lemon: occasional item requests traded for next-dungeon bias or temporary
  perks; llm-mode persuasion or complaints could influence the bargain.
- Compass: currently mostly a gate indicator; the player wants a menu containing
  appropriately moved functions.
- Workstations: crafting, anvil, grindstone and similar blocks could have
  placement counts, durability, or refill requirements.
- Loot utility: cobblestone is valuable because it crafts tools and furnaces;
  slime balls had little use; no sand meant no glass for potion brewing.
- Room identity: Breeze Arena's lava felt wrong for the name; the player expects
  a breeze-appropriate hazard and thinks lava better fits a Blaze Arena.
- Room geometry: more ceiling-high interior walls, tighter routes, and pillars
  that deliberately cover lamps would build on the lighting mechanic.

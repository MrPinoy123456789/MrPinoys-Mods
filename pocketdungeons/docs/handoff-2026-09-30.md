## How to work here

- Test server: `node tools/server/pdserver.mjs start|stop|status|cmd "<cmd>"`
  from `pocketdungeons/` (builds from source; the world saves on stop). Check
  `status` for players online before restarting, and warn them in chat.
- Room templates are baked `.nbt` files. After changing a `RoomSpec`, restart,
  run `dungeon admin gentemplates <room>` (one room only, not the library),
  restart again to load it, and check with `dungeon admin plansurvey 100` and
  `dungeon admin coverage`.
- Tests: `./gradlew build` (unit tests), `./gradlew runGameTest` (gametests;
  new classes register in `src/gametest/resources/fabric.mod.json`).
- Playtests: the `playtest` skill debriefs a session; findings go in
  `docs/playtests/`, bugs in `docs/reference/BUGS.md` (next ID PD-92).
- Lemon (the in-game interviewer) runs through `tools/server/mcp.mjs`; see
  `tools/lemon/README.md` and `docs/LEMON_AGENT.md`.
- Files mix CRLF and LF line endings; edit with the Edit tool or a script that
  keeps each file's existing ending.

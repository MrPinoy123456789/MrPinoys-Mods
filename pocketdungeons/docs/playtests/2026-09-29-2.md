### Proposals, not code

**Home cannot grow a tree.** The safe room interior is Y=1..5 under a ceiling at Y=6, and the floor is protected shell, so a sapling on placed dirt sits at Y=2 with four blocks above it; vanilla oak wants about seven. Options, cheapest first: (a) let the owner swap floor tiles for dirt (floor stays shell but a dirt, grass or moss block is accepted in place), which buys one block and still is not enough for an oak; (b) a tall home variant built on the existing `spanY` machinery (M61), a two-story shell with the floor between the stories left out, giving about thirteen blocks of headroom, unlocked like a shell palette; (c) accept it and say so in the home's help text, pointing at azalea and bushes. Recommendation: (b) as a shell unlock, since the story geometry and protection already handle two stories.

**Blocks have no job.** `blocks` is already a capability tag (`SituationTags.BLOCKS`) and four rooms use it, `ropewalk` (a high crossing with a slow low path) and `sump` among them, but only as an optional shortcut the player can ignore, so building blocks read as clutter. Proposal for the room pass: one traversal room where the fast route is a climb (a `spanY` 2 shaft whose exit door is on the upper story, with a slow ladder route round the side) and one where a bridged gap saves a long lava detour, both advertising the shortcut from the doorway. The player's scattered floor obstruction idea fits the same pass.

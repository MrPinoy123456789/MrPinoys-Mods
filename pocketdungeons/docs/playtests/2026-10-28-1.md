## Harness notes

- No Lemon MCP configured: fell back to shell tools, which is expected on
  CLI. Tell the owner if MCP was supposed to be registered.
- Driver namespace differs by deployment: standalone build `lemon ...` vs
  this server's `dungeon lemon ...`. The shared `lemon` verb and `context`
  in playtest.mjs assume the standalone build and fail on this one.
- `context` verb unusable here (needs `lemon context`); `cmd "dungeon admin
  context <p>"` is the working substitute and also returns Lemon state.
- Keepalive via `cmd` costs a marker command and a failed read each tick
  once the log broke; harmless but noisy in the log.
- The heightmap WARN flood (chunkgen while players fly) is what blew the
  log past the editor limit; it also floods the event stream.

# Pocket Dungeons

A server-side Fabric mod for MC 26.2. `/dungeon` to go in.

## Where to start

All milestones M0–M9 are code-complete. Read `plans/COMPLETED-MILESTONES.md`
for what was built, and `docs/LIVE_TEST_PASS.md` for the outstanding live verification
pass.

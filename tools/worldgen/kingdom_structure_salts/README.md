# Kingdom structure salts

A world datapack that gives ancient cities and trial chambers a salt of their own, so a leaked world seed does not lead
players to them. Spacing and separation are vanilla (24/8 and 34/12); only the salt differs.

- Install: copy this folder into the world's `datapacks` folder as `kingdom_structure_salts`, restart, and check
  `datapack list` shows it enabled.
- It only changes chunks generated after it is installed. Structures already in generated chunks stay where they are.
- The two salt values are a secret of the server. Do not publish this folder or the world's datapacks.
- If a Minecraft update changes the vanilla definitions, copy the new ones from the game jar and change only the salt.

# Charter Currency

**Strike coin, earn Valor, raise your kingdom's Renown.**

The currency mod for the Kingdoms (charter) server. Server-side Fabric, Minecraft
26.2, JDK 25. Vanilla clients need nothing installed.

> **Status:** approved design, 2026-10-31. Not built yet.

| Currency | For | In short |
|---|---|---|
| Coin (Copper Mark 1, Iron Crown 8, Gold Sovereign 64) | Players | Money. Struck from metal at a capped Mint, traded freely |
| Valor | Players | A medal. Earned in dungeons and events, never traded |
| Renown | Kingdoms | Earned alongside Valor, spent on the charter catalogue |

- [SPEC.md](SPEC.md): the build spec. Hand this to whoever builds the mod.
- [REVIEW.md](REVIEW.md): background from the design review.

Forked from [Cobble Economy](../cobbleeconomy); it does not depend on it, and the
two never run on the same server.

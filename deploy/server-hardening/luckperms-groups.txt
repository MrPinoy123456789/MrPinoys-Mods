# LuckPerms groups for the kingdom server d212ecae. Console commands, one per line (no leading slash).

# LuckPerms, or with: node tools/playtest/hardening-stage.mjs --lp-setup --owner-approved
# Reasons and the full node table: docs/SERVER_HARDENING.md, section "Permission groups".
#
# NEVER grant "*", "race.*" or any "race.<kingdom>" node in LuckPerms. Charter answers race nodes
# (Foundry's race weapons, looks, glide, double jump and swim dash read them); a wildcard here would
# give a staff member every race at once. Never grant "luckperms.*" to anyone but the owner.

lp creategroup helper
lp creategroup builder
lp creategroup moderator
lp creategroup admin
lp group helper setweight 10
lp group builder setweight 15
lp group moderator setweight 20
lp group admin setweight 30
lp group moderator parent add helper
lp group admin parent add moderator

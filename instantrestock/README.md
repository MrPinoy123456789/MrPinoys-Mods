# Instant Restock

A small server-side Fabric mod for Minecraft 26.3. A villager's trades come back the moment one is used, so a trade can be
repeated as often as the player has the items. Prices and demand are left as they are, so a villager does not get dearer
for being traded with. Wandering traders are not changed.

It has no settings: installing it turns it on, removing it turns it off. It runs on the server only, so Java players and
Bedrock players through Geyser see the same thing.

Build with `./gradlew.bat build`. The jar is `build/libs/MrPinoys_InstantRestock-0.1.0.jar`.

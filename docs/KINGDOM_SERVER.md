# The kingdom server (d212ecae)

The owner's shipped Fabric server: Charter, Lemon, Foundry, Polymer, Geyser and Floodgate (Bedrock), plus worldgen
packs. Deploy with the `deploy-shipped-server` skill. The player facing handbook is the owner's Server Manual
artifact; this file is for agents.

## Shape of the game

- Five kingdoms, created by ops only (`/charter admin faction create`) and led by a player an op appoints. Each is a
  race: Azrak (Dwarf), Aurelia (Human), Azurius (Merfolk), Faeloria (Fae), Everdelle (Fairy). A kingdom's keep is a
  permanent 9 by 9 chunk square that cannot be lost; the keep granary is off.
- Outposts are the only extra claims (overworld only). They hold points of interest and give fast travel; wars are
  fought between touching outposts. Players cannot found, dissolve or secede (`playerFounding` false).
- Charter publishes a read only map of held land for other mods: `charter/docs/AREAS_API.md`. Structures do not
  generate inside held land (`StructureMixin`).
- World: seed 3806707291501128365, border 10000 across centred on 0,0, the End off. Dungeons and Taverns, Structory
  and Incendium add structures. Pregeneration is partial; the rest generates on demand.

## Race weapons

Five weapons, three tiers each, in `foundry/examples/content`: `kingdoms:azrak_pick_N`, `aurelia_oathblade_N`,
`azurius_trident_N`, `faeloria_staff_N` and `demo:fairy_wand` (tiers 2 and 3 are `_2`, `_3`). All are generated by
`foundry/tools/gen_weapons.py`; never hand edit the JSON, change the script and re-run it. Upgrades are shapeless
recipes with the lower tier first, unlocked through generated advancements.

- Each weapon has `require_permission` `race:<kingdom>`. Charter answers that node for members (`RaceNodes`), through
  the Fabric permission API. Ops pass the lock. A race mod can grant the same nodes later.
- `keep_on_death` keeps the weapon with its owner. `handheld` makes the icon held like a tool.
- Base items are bone (trident), blaze rod (staff), breeze rod (wand), stone pickaxe, iron sword. Never use `stick`:
  Litematica uses it as a client tool.
- Bedrock: Geyser cannot read Polymer models. `foundry/tools/gen_bedrock.py` writes the Geyser mappings and the
  Bedrock pack; deploy with `--bedrock`. Geyser needs `enable-custom-content: true` (already set).

## Branches and Minecraft versions

Master is on Minecraft 26.3 (Charter, Lemon, Foundry). Pocket Dungeons and the rest are on their own schedule; check
each module's `gradle.properties`. A version bump is its own branch (`feature/minecraft-26-N`): change the loom
versions, then fix what no longer compiles (26.3 moved `Player.drop` to `spawnAtLocation`). Port, build, run the
gametests, then merge to master before deploying so master never lags the server.

## Things that are not obvious

- Gametest mock players have no Charter membership. Foundry's `TestPerms` grants nodes through the real permission
  API; Charter's `RaceNodeGameTest` checks the Charter side.
- `keep_on_death` stacks live in memory between death and respawn. A server stop on the death screen loses them.
- The Charter tutorial still teaches player founding and needs a rewrite for ops set kingdoms.
- Old Mossbeard's Muddle (the admin kingdom at spawn) has not been re-founded in the current world.

## Server build notes

- The panel's version switch installs vanilla and deletes the Fabric launcher; never use it. The launcher was rebuilt with Fabric's installer.
- Bedrock joins only through Geyser with `bedrock.transport: both` and the WebRTC settings; see the owner's Server Manual.
- Rollback material in the server root: `world-before-26.3.tar.gz`, `/mods_26.2_set`, and `/mods_backup` (jars before each deploy).
